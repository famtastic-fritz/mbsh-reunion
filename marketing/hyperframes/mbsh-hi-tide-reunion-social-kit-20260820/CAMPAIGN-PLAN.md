# Nine-Post Social Proof Plan

| Asset | Post purpose | Deterministic overlay copy |
| --- | --- | --- |
| 01-red-carpet-roll-call | Announcement | The call is out. |
| 02-golden-ticket | Registration prompt | Your invitation is waiting. |
| 03-memory-reel | Memory prompt | The story never stopped. |
| 04-dance-floor | Celebration | Bring your reunion energy. |
| 05-time-capsule | Nostalgia | What would 1996 say to you now? |
| 06-photo-booth-flash | Social sharing | Make room for one more memory. |
| 07-velvet-spotlight | Premium event statement | This reunion deserves an entrance. |
| 08-then-and-now | Alumni continuity | Then and now—still Hi-Tide. |
| 09-final-call | Conversion | Join the roll call. |

Every finished post should use HTML/CSS or a design-system overlay for captions,
event information, and calls to action. Generated images are never the source
of factual dates, payment details, or final user-facing wording.
