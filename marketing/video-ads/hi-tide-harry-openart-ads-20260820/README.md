# Hi-Tide Harry — OpenArt Ad Set

Three vertical MBSH reunion ads built from the OpenArt/Kling Hi-Tide Harry movie trilogy.

## Deliverables

- `hyperframes/` — 15-second assembled campaign trailer, editable in HyperFrames.
- `remotion/` — three independent 5-second ad compositions plus the assembled trailer, editable in Remotion Studio.
- `CAMPAIGN-COPY.md` — deterministic on-screen copy and the matching post captions.

The source movies are referenced as local, version-controlled assets. No raw footage was duplicated into this package.

## Rendering boundary

The user requested the ads and the two editable production formats. The final MP4 render remains deliberately gated on a visual review of the source compositions; this package does not schedule, publish, or deploy anything.
