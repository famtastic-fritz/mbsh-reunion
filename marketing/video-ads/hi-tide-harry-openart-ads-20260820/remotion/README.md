# Hi-Tide Harry — Remotion Ads

This project contains four 9:16 compositions at 24 fps:

- `Grand-Return`
- `Roll-Call`
- `Memory-Opens`
- `Master-Trailer` — the three cuts in sequence, with film-burn bridges

The videos in `public/assets/` are frozen local copies of the approved OpenArt
movie source assets. They are deliberately vendored so the Remotion bundle and
render are portable; do not replace them in place.

## Local review

```bash
npm run dev
```

Review at phone size before approving a final render. The companion copy is in
`../CAMPAIGN-COPY.md`.
