# Private archive source manifest

Status: private source references only
Recorded: 2026-08-16

The source files below are intentionally **not copied into Git**. They contain
real faces, names, signatures, and other personal information. Checksums let the
team identify the source without publishing it. Any use must follow:

`private original -> validation/quarantine -> human rights review -> redaction
and derivative creation -> explicit approval -> public collection`

No automatic face identification is permitted. Names and faces may be tagged
only through consent or human verification. Diploma signatures and full names
must be removed from public derivatives unless the owner explicitly approves
that exact use.

## Approved derivative ideas

- red leather grain, cream paper, gold-foil linework, and school-building
  engraving textures with all names/signatures removed;
- a user-controlled diploma-opening transition for forms and confirmations;
- an archival yearbook page-turn component populated only with approved media;
- a “then and now” collection using volunteered images and explicit visibility;
- a private OCR/index for curators, with no automatic public face/name matching.
