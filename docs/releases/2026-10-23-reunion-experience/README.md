This release promotes only the changed/new frontend and PHP paths from the tested Git commit, after verifying prior live files against source baseline `62f714c242fd6936db7252b2a22f46c8ca7defd6`. It does not replay unrelated files from an older full release. Immutable before/after files, manifest, migration and private pre-migration activity-table snapshot are retained under the release directory listed in the receipt. No `rsync --delete`, shared root cleanup or broad database restore is used.

Apply the additive `backend/migrations/20261023_reunion_experience.sql` before switching runtime files. Rollback uses the recorded immutable baseline files for exactly the release paths, moving newly introduced runtime paths into the private release archive. Preserve additive tables, submissions, scores, audit, provider events, uploads, Woo orders and tickets. Do not run a down migration or restore an entire database over newer records.
